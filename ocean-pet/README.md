# 海洋女仆桌宠

Windows 10/11 独立桌宠，以提供的参考视频制作透明动画。无需安装 Python，与小太阳使用不同的程序、配置和开机启动项，可同时保留。

从 GitHub Release 下载 `OceanMaid-Setup-版本-构建时间.exe` 安装，桌面或开始菜单启动。安装包未签名；随包提供 SHA256 校验文件。默认安装到当前用户的 `LocalAppData/Programs/OceanMaidDesktopPet`，设置保存在 `LocalAppData/OceanMaidDesktopPet/settings.json`。升级和卸载均保留设置。

- 单击角色：播放低头、保持、抬头微笑动作；互动中重复点击不排队。
- 按住角色拖动：移动到目标位置，释放后保存；拖拽不触发新的互动。
- 右键角色或托盘图标：互动、恢复待机、暂停、隐藏、尺寸、置顶、自动打招呼、开机启动和退出。
- 双击托盘图标：重新显示隐藏的桌宠。
- 默认高度 280，可选 150/200/280/350 或自定义 150–800；尺寸随屏幕 DPI 缩放且保持比例。
- 默认静音，不开启开机启动，不开启随机打招呼。待机使用原视频的小幅动作片段。
- 暂停、隐藏、锁屏会冻结动画进度，恢复后继续；更换显示器时修正屏外位置。

视频主体采用原始透明帧，保留参考动作节奏。原视频末尾双手下落，程序追加短抬手复位片段和姿态过渡再回到待机，完整互动约 11.5 秒。源视频部分帧的尾鳍、鞋底触边裁切仍保留；未提供原始立绘，不能宣称已完成与原图逐细节一致的验收。预览脚本和旧素材保留在制作工作区，不作为正式运行入口。

## 构建与测试

使用系统 .NET Framework C# 编译器，运行 `tools/build-app.ps1` 创建独立构建目录，然后运行 `tools/test-app.ps1 -AppDirectory <构建目录>`。测试使用隔离配置，包含状态边界、重复点击、冻结恢复、多屏坐标、配置读写及真实分层窗口、托盘、菜单生命周期与完整动作。

`tools/build-installer.ps1` 构建带台北时间戳的 NSIS 3.11 安装包。构建过程保留旧目录和旧包；正式载荷只包含程序、透明帧、图标、清单和说明。测试日志、个人数据、原视频、评审材料和本机路径不进入公开发布。

测试记录只代表实际执行范围：自动化覆盖 Windows 11 上的本地状态及窗口功能；没有实测的 Windows 10 设备、多种物理显示器组合和长时间运行不作保证。安装向导可生成、校验和独立启动载荷，真实安装/升级/卸载环境验收需另行记录。
